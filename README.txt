WERWOLF SPIELLEITER PWA

Alle Dateien liegen absichtlich im Hauptverzeichnis, damit der Upload über die GitHub-Weboberfläche einfach ist.
Die Hexenkarte verwendet keine externe Bilddatei. Die Hexenkarte wird rein per CSS als neutrale dunkelgrüne Rollenkarte dargestellt.
Die App-Icons app-icon-192.png, app-icon-512.png, app-icon-maskable.png und apple-touch-icon.png wurden aus dem bereitgestellten Werwolf-/Mond-Bild erzeugt.

GitHub Pages:
1. Alle Dateien dieses Ordners gemeinsam ins Repository hochladen.
2. Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Die veröffentlichte HTTPS-Adresse öffnen.
4. iPhone/iPad: Safari > Teilen > Zum Home-Bildschirm.
5. Android: Chrome > Menü > App installieren / Zum Startbildschirm hinzufügen.
6. Nach dem ersten vollständigen Laden funktioniert die App offline.
